# 青梅 · 个人助理框架

> 一台属于你自己的机器，一个以插件为最小单位生长的个人助理。
> 同一个「人格 + 记忆 + 任务账本」，同时出现在 QQ、飞书、网页、桌面和手机上。

青梅不是一个聊天框，也不是一个机器人脚本。它把「个人助理」拆成一组互相不知道对方存在的插件：
模型、存储、渠道、工具、记忆策略、宿主界面，全部可替换、可卸载、可热重载。
核心只提供两样东西：**一个 Cordis 应用容器**，和**一组服务契约**。

---

## 它解决什么

| 现状 | 青梅的答案 |
| --- | --- |
| 助手散落在各个 App：日程在手机、文档在网盘、待办在便签、对话在微信 | 一个账本：记忆、日程、任务、对话共用同一套数据模型 |
| 每个平台重写一遍机器人，QQ 一套、飞书一套、网页一套 | 渠道只是适配器，业务逻辑只有一份 |
| 想换模型 / 换数据库 / 换界面 = 重写 | 换的是插件，契约不变 |
| 数据在别人服务器上，不想让私人事项进云端模型 | 本地优先存储；敏感数据可路由到本地模型，不出网 |
| 只会被动应答，不会主动提醒 | 日程、任务、目标是一等公民，主动巡检是内置服务 |
| 用半年还是刚装的样子 | 记忆有巩固与遗忘；故障修一次记一次，下次秒级自愈（[08](docs/08-自进化与自修复.md)、[09](docs/09-神经元记忆核心.md)） |
| 只会等你开口 | 自主循环：自己判断什么时候该出现、该派任务、该闭嘴（[13](docs/13-主动性架构.md)） |

## 五条不可让步的约束

1. **万物皆插件。** 内核不含业务。没有「核心功能」，只有「服务定义 + 提供方 + 消费方」。
2. **一个助理，多个门。** 渠道和宿主都是传输层，不持有业务状态；换个入口，还是同一个人。
3. **数据在你手里。** 默认 SQLite 单文件，默认不出网；出网是显式策略，不是默认行为。
4. **记忆是核心，不是配件。** 它不可热卸载；它也不是一次向量检索——它有衰减、有巩固、有遗忘。
5. **一个记忆，多个视口。** 端上只有缓存；在电脑上说过的事，手机上必须记得。

## 架构一分钟

```text
宿主 Hosts        Web(Vue3) · Electron(EXE) · Capacitor(APK) · CLI · 无头
                        │  HTTP / SSE / WebSocket
网关 Gateway      鉴权 · 会话 · 事件流 · 幂等 · 限流
                        │
渠道 Channels     QQ(OneBot11/NapCat) · 飞书(长连接) · Web · 邮件/短信
                        │  InboundMessage / OutboundEnvelope
────────────────────────┴───────────────── 业务层（全部是插件） ────────────────
编排 Agent        人格注入 · 上下文组装 · 工具循环 · 预算与超时
能力 Services     llm · memory · persona · tools · schedule · store ·
                  identity · permission · audit · notify · skills · sync
提供方 Providers  sqlite/postgres · deepseek/ollama/openai · onebot/feishu · …
────────────────────────┬─────────────────────────────────────────────────────
内核 Kernel       cordis：Context · Plugin · Fiber · Effect · Service · inject
```

harness（DSH / ZCode / Claude Code…）通过 **ACP** 被青梅拉起和调度，通过 **MCP** 回调上报进度、
申请审批；青梅不越界去改它们的界面。见 [07](docs/07-Harness协作协议.md)。

## 术语

| 词 | 含义 |
| --- | --- |
| 青梅 / QM | 本框架的产品名；包作用域 `@qingmei/*`，命令 `qm` |
| 宿主 Host | 用户直接看到的界面进程：Web、桌面、手机、终端 |
| 渠道 Channel | 消息进出的平台：QQ、飞书、Web、邮件 |
| 会话 Session | 一次连续对话的上下文边界，跨渠道共享同一身份时也共享记忆 |
| 事实 Fact | 从对话中抽取、可被召回的最小记忆单元（带来源与置信度） |
| 技能 Skill | 一组提示词 + 工具 + 流程的组合包，按需渐进加载 |
| 打扰预算 | 主动提醒每天允许的次数与静默时段，防止变成骚扰 |
