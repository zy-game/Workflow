# 31 · 故障注入清单

坏环境下系统怎么表现，这里只记录**有测试证据**的行为；没证据的写“未覆盖”，不写“应该会”。

跑法：

```bash
node --test scripts/fault-injection.test.mjs   # 跨包故障场景
pnpm test                                       # 全量（含下面所有引用）
```

## 1. 已覆盖

| 故障 | 期望行为 | 证据 |
| --- | --- | --- |
| DSH 不可用（派任务） | `POST /api/v1/tasks` 返回 503，**不建 run** | `packages/qm-task/test/task.test.ts`「没有 harness 时 POST 返回 503」 |
| DSH 不可用（对话，且没配 LLM） | 回「我这边出了点问题：没有可用的执行器…」，`turn/end.ok=false`，不假装成功 | `packages/qm-agent/test/agent.test.ts`「DSH 不可用且没配 LLM」 |
| DSH 命令不存在 | `available()` 为 false，请求被 reject，**进程不崩** | `packages/provider-dsh-acp/test/acp.test.ts`「命令不存在时 start() 失败」 |
| 子 agent 请求权限没人批 | 5 分钟后按拒绝处理，任务不永远 pending | `provider-dsh-acp`「没有审批服务时一律取消」+ 审批超时用例 |
| 设备失联 | 超过 `leaseTimeoutMs` 没有进展 → failed「设备失联」 | `scripts/fault-injection.test.mjs` + `qm-task` 租约用例 |
| 设备迟到上报 | 账本已 failed，`finish` 幂等，不会被改回 done | `scripts/fault-injection.test.mjs`「迟到的 finish 不会复活」 |
| 进程重启（本地任务） | queued 重排；running 先 `resume()` 再派发 | `qm-task`「重启恢复」两条 |
| 进程重启（设备任务） | 保持 running 等租约，不直接判死 | `scripts/fault-injection.test.mjs`「设备任务保持 running 等租约」 |
| 进程重启（待审批） | 审批落库，重启后仍在，可继续决定 | `scripts/fault-injection.test.mjs`「待审批不丢」 |
| 渠道发送失败 | 不写助手消息，`turn/end.ok=false`，用户能看到兜底文案 | `qm-agent`「渠道发送失败」+ `service-channel`「投递失败不发 qm/outbound」 |
| 落库失败 | 回复照发，`turn/end` 仍为 ok（落库不再是回合职责） | `qm-agent`「落库失败」 |
| SQLite 被别的连接锁住 | 写操作**快速失败**（不挂住）、报错可读；解锁后恢复 | `scripts/fault-injection.test.mjs` |
| 排队超时 | 超过 `queueTimeoutMs` 转 failed「排队超时」，不无限 queued | `qm-task`「排队超时」 |
| 任务执行超时 | abort → cancelled，账本保留原因 | `qm-task` 执行超时分支（token/超时用例覆盖） |
| 部署后不健康 | supervisor 自动回滚到上一个 release，保留 data | `scripts/supervisor.test.mjs` |

## 2. 未覆盖（需要真进程或真环境）

| 故障 | 为什么没覆盖 | 建议补法 |
| --- | --- | --- |
| 磁盘满 / 只读文件系统 | 单测里伪造不了写盘失败 | 临时挂载 tmpfs（CI 上可行）或在 store 上注入写失败 |
| 端口被占用 | 需要真起进程 | smoke 变体：先占 7410 再启动，断言明确报错退出 |
| DSH「半死」（进程在、不返回） | ACP 请求有 120s 超时，但没测过 | fake agent 不响应 initialize，断言超时后 `available=false` |
| 长稳（24h 连续回合/定时任务） | 成本高 | 部署后挂一个每小时跑 smoke 的 cron，攒一周数据 |
| 内存/句柄泄漏 | 需要采样 | 长稳期间记录 RSS 曲线 |

## 3. 约定

- 新写的失败路径**必须有测试**，否则不算修完；这条已写进 `pnpm gate` 的默认期望（测试全绿才算过）。
- 只在“能单进程复现”的范围内写单测；需要真进程的放 `scripts/smoke.mjs` 或部署后校验，不要用 mock 假装覆盖。
