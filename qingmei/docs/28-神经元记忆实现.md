# 纯神经元记忆实现

当前落地包：

```text
packages/provider-neuron-memory
```

它替换了旧的 `provider-memory-sqlite`，不再使用 FTS、向量库或 LLM 抽取。

## 模型

```text
Neuron   神经单元
Synapse  点触
Episode  事件
Binding  事件/事实与神经元的绑定
```

集合：

```text
qm_neuron
qm_synapse
qm_episode
qm_neuron_binding
qm_mem_fact
```

## 编码

确定性分词：

```text
中文：单字 + 双字 + 整段
英文/数字：词
```

这是感知编码，不是语义模型。  
语义来自后续点触学习。

## 召回

```text
文本 → 种子神经元
→ 阈值发放
→ 沿点触扩散
→ 事件/事实绑定打分
```

没有 cosine，没有 ANN。

## 学习

```text
共同发放 → 点触增强
长期不用 → 衰减/剪枝
```

## 沉淀

```text
夜间 replay 高显著事件
→ 加强共同激活
→ 衰减弱边/剪枝
```

当前是“重放 + 衰减”的沉淀；概念神经元/合并分裂是下一阶段。

## 迁移

旧 `qm_mem_fact` 行会在后台补神经元绑定；  
补绑完成前，召回仍有词面兜底，不阻塞接口。
