# 失败语义、成熟度门禁与自治路线

## 1. 失败语义

### 原则

```text
不承诺无限可用。
失败必须快速、可见、可恢复。
```

### 交互式聊天

```text
DSH 不可用
→ 不静默切换不健康的 LLM
→ 当前回合返回明确失败文案
→ turnEnd.ok=false
→ 用户可重试
```

只有显式配置且健康的 LLM 才允许作为 chat 降级；不能用于需要工具/文件/设备的任务。

### 同步任务创建

```text
local 执行器无 harness
→ POST /api/v1/tasks 返回 503
→ 不创建 run
```

### 异步任务

```text
已接受但暂时没有执行器
→ 保持 queued
→ 有队首年龄和等待原因
→ 超过 queueTimeoutMs 转 failed
→ error 记录“排队超时”
```

当前 `qm-task` 已有 `queueTimeoutMs`，默认 24 小时；到点由 runner 扫描并把长期 queued 的 run 收为 failed。

测试接缝：`startPaused` + `resumeOnRestart()`。先建队列，再启动 runner，不靠 provider 插件迁就测试。

后续可增加显式 `blocked` 状态，但不应引入“无限 queued”。

### 设备任务

```text
设备离线
→ 任务保持 queued
→ 设备重新 claim 时可继续
→ 超过 queueTimeoutMs 失败
```

不要把“设备不在线”当成无限挂起。

### 模型池

```text
每个 provider 有健康检查
有顺序/优先级
有最大重试
全挂 → 明确失败
```

模型池只解决“还有没有可用模型”，不解决“任务是否应该继续等”。

## 2. 成熟度门禁

### Gate 0：静态

```text
tsc --noEmit
lint
architecture check
```

当前仓库主要依赖 Node type stripping；需要补真正的类型检查门禁。

### Gate 1：单元

```text
node --test
```

覆盖状态机、权限、记忆、任务、审批。

### Gate 2：集成/冒烟

```text
healthz
发消息
历史落库
重启持久化
设备任务 claim/finish
审批创建/决定
```

### Gate 3：故障注入

```text
DSH 不可用
设备离线
数据库锁/磁盘满
队列超时
渠道发送失败
进程中途重启
```

### Gate 4：评估

```text
记忆：recall@k / 误召回 / 延迟 / 成本
任务：成功率 / 平均完成时间 / 排队 P95
对话：失败率 / 重试率
```

没有评估，不建议继续加“更聪明”的自动能力。

### Gate 5：发布

```text
备份
健康检查
灰度
回滚演练
```

### Gate 6：自治

见下一节；自治能力必须晚于 Gate 0–5。

## 3. 当前成熟度

```text
核心助手链路：可部署原型
任务/设备/审批：可部署原型
记忆：可用但弱
自我优化：实验级
进化：概念级
```

已知缺口：

```text
tsc --noEmit 目前只覆盖 provider-neuron-memory，全仓类型检查仍未接入
没有记忆质量评估
没有故障注入/长稳测试
没有模型池健康检查
```

## 4. 自治与进化

### 当前状态

```text
qm-autonomy：默认装配 A1/A0 观察；记忆沉淀只发建议，不自动执行
qm-incident：已并入 qm-autonomy 子模块
qm-review：复盘
```

它们不是“自己变聪明”，而是：

```text
规则/事件 → 建议/报告 → 人决定
```

默认已移到 experimental。

### 分级

```text
A0 建议：只产生建议，不改系统
A1 有界调参：只改白名单参数，有上下限
A2 沙箱试运行：生成 prompt/skill/配置，在隔离环境评估
A3 代码提案：生成 patch/PR，不自动合并
A4 自动合并：当前不建议
```

### 闭环

```text
观察指标
→ 生成提案
→ 沙箱执行
→ 评估对比
→ 人工/策略审批
→ 灰度
→ 监控
→ 回滚
```

### 硬约束

```text
不能在主进程直接自改代码
不能跳过审批
不能没有回滚
不能没有评估集
不能无预算运行
```

### 记忆的“进化”

允许：

```text
事实冲突检测
时间失效
低价值压缩
用户显式纠正
```

不允许：

```text
模型自行改写人格/安全规则
模型自行删除审计
模型自行扩大权限
```
