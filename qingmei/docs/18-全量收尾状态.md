## 3. 明确未做（不是遗漏）

1. **S2 代码级自动修改**：只自动诊断和派任务，不自动改代码；L1 提示词走 R 的提案+一键应用。原因：代码自修改风险高于收益，保持人工确认。
2. **S1 自动补丁 L3 拒绝策略**：`scripts/patch-scope.mjs` 已实现；自动补丁部署必须过 L3 路径拒绝，手动发布不受影响。
3. **A4 模型判断热点**：规则版热点 + 周报 + 日报已做；没有 LLM 热点判断和环境自维护。
4. **R 按标签/人格版本聚合**：只有总体评分和逐条卡片，未按标签聚合。
5. **移动端 sidecar、首次启动向导、三端一致性实测**：未做；代码签名按决定不做。
6. **桌面系统级验收**：NSIS 安装包已构建（约 110MB），静默安装在当前环境被 UAC 提权卡住；更新源 `latest.yml` 与安装包 HTTP 200 已验；开机自启/隐藏通知/多屏/DPI 与自动更新真实升级仍未在干净 Windows 环境完成端到端演练。代码中的窗口越界回夹、全屏隐藏、autostart、更新源已具备。
7. **M6 生态**：市场/文档站/在线安装源明确不做。

## 4. 收尾判据

满足以下条件即视为个人版全量收尾：

- 主线与个人版里程碑测试通过；
- 生产服务健康，部署可回滚；
- G/R 的后台操作在 Web 可用；
- 移动端可安装、登录、聊天、悬浮；
- 剩余项均属于上述“明确未做”或 Future，不再有“未知遗漏”。

当前状态满足该判据；第 3 节第 6 条是唯一需要真实 Windows 安装环境补证的系统级项。
