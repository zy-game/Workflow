# 记忆架构：事实 + FTS + 向量 + 可选关系图

这是青梅按 Jarvis 方向演进时的记忆实现路线，不是当前全部已实现。

## 1. 分层

```text
canonical     事实 / 笔记 / 承诺
retrieval     FTS5 + 向量
relations     人物 / 项目 / 承诺 / 时间
```

### canonical

建议 SQLite：

```text
qm_mem_fact
  id
  subject
  predicate
  object
  confidence
  salience
  sensitivity
  audience
  device
  valid_from
  valid_to
  origin_kind
  origin_id
  created_at

qm_mem_note
  id
  title
  body
  audience
  valid_from
  valid_to
  created_at
```

`valid_to` 做软失效，不物理删除；用户「忘掉」只设置失效并清索引。

### FTS

```text
qm_fact_fts
  id UNINDEXED
  text
```

只索引：

```text
subject + predicate + object
note.title + note.body
```

### 向量

两种落地：

```text
A. Orama
   索引对象持久化成文件/JSON
   纯 JS，不需要扩展

B. sqlite-vec
   向量列在同一 SQLite
   Node 需要加载扩展
```

建议字段：

```text
id
kind          fact | note | summary
embedding     vector
model         embedding 模型名
dim           维度
created_at
```

必须记录 `model` 和 `dim`，否则模型升级后无法判断旧向量是否兼容。

### 关系/时间图

先做最小表，不急着上图数据库：

```text
qm_mem_edge
  from_id
  relation
  to_id
  valid_from
  valid_to
  confidence
```

适合：

```text
人物关系
项目归属
承诺对象
事件时间线
```

如果以后需要多跳查询，再接 Graphiti / Zep / Neo4j。

## 2. 写入

```text
显式「记住」
人工修正
经审批的自动抽取
```

默认不做每轮 LLM 抽取。

写入流程：

```text
规范化
→ 去重/冲突检测
→ 写 canonical
→ 更新 FTS
→ 入 embedding 队列
→ 异步写向量
```

embedding 失败不能阻塞事实写入。

## 3. 召回

```text
过滤 audience/sensitivity/validity
→ FTS topK
→ vector topK
→ RRF 融合
→ 可选图扩展
→ 上下文预算裁剪
→ 注入 prompt
```

不要只做 `cosine topK`；必须有元数据过滤和失效过滤。

## 4. 模型

推荐本地：

```text
Ollama
  bge-m3
  nomic-embed-text
```

或：

```text
transformers.js
  multilingual-e5
```

中文优先 `bge-m3`。  
不要自己写 hash embedding 充当语义向量。

## 5. 索引任务

```text
qm_mem_index_job
  id
  memory_id
  kind
  status: pending | running | done | failed
  attempts
  error
  created_at
```

这样 embedding 服务挂掉时：

```text
事实仍然可写
FTS 仍然可查
向量稍后补
```

## 6. 隐私

```text
owner / group / device
sensitivity: public | private | secret
```

secret 默认不进入普通召回；  
群聊只召回 public 且 audience 匹配的事实。

## 7. 评估

```text
recall@5
precision@5
误召回率
无结果率
延迟
embedding 成本
```

先准备 50–100 条真实查询，再决定是否把向量设为默认。

## 8. 迁移顺序

```text
1. 保留事实 + FTS5
2. 增加 qm_mem_note 与 index job
3. 接本地 embedding，异步索引
4. 加 Orama 或 sqlite-vec
5. 做 RRF 融合
6. 需要多跳时再加关系图
```

不要一次性把图数据库、向量库、LLM 抽取全上。
