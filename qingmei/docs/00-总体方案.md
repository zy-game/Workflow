# 00 · 总体方案

> 一页纸看懂青梅：它是什么、怎么搭、一天怎么跑、先做哪块、还有哪些没定。
> 细节都在各分篇里，本文只负责把它们串成一条线。

## 1. 一句话

**青梅是一个跑在你自己服务器上的个人助理。记忆、判断、主动性在青梅；动手的是可替换的 harness。**

它不是聊天框，不是 RPA 脚本，也不是又一个 LLM 前端。三条体验指标：

- **记得住**：三个月前说的事，今天还能召回。
- **接得上**：电脑上做的事，手机上问一句能续上。
- **该出现时出现**：没事不吵，有事提前。

## 2. 五条不可让步的约束

| # | 约束 | 意味着 |
| --- | --- | --- |
| 1 | 万物皆插件 | 内核不含业务；能力 = 服务定义 + 提供方 + 消费方 |
| 2 | 一个助理，多个门 | 渠道与宿主不持有业务状态，换个入口还是同一个人 |
| 3 | 数据在你手里 | 默认 SQLite 单文件、默认不出网；出网是显式策略 |
| 4 | 记忆是核心 | 不可热卸载；有衰减、巩固、遗忘，不是一次向量检索 |
| 5 | 一个记忆，多个视口 | 端上只有缓存；电脑上说过的事手机上必须记得 |

## 3. 架构全景

```text
宿主   Web(Vue3) · Electron(EXE) · Capacitor(APK) · CLI · Watch(仅渠道)
                    │ HTTP / SSE / WS
网关   gateway（鉴权/会话/事件流/幂等）
                    │
渠道   QQ(OneBot11) · 飞书(长连接) · Web · Watch
                    │ InboundMessage / OutboundMessage
────────────────────┴──────────────── 业务（全是插件）────────────────────
治理   conversation（画像） · permission · audit · identity
编排   autonomy（自主循环/排期） · qm-agent（信封+会话）
执行   harness（ACP 拉起 DSH/ZCode） · mcp-server（收进度/审批/记忆）
核心   memory（神经元图） · persona（自我模型） · self（自省/自修复）
能力   llm · tools · schedule · store · notify · skills · sync
────────────────────┬───────────────────────────────────────────────────
实现   sqlite · deepseek/ollama · onebot/feishu · acp/cli
内核   cordis@4：Context · Plugin · Fiber · Effect · Service · inject
```

四个关键关系：

- **青梅 = 治理层 + 核心层**；推理与表达委托给内嵌 DSH（ADR-013）。
- **harness = 子 agent**：控制面 ACP，数据面 MCP（[07](07-Harness协作协议.md)）。
- **规则三分**：硬边界写代码、场景策略写数据、表达判断写提示词（[12](12-规则分层-代码策略与提示词.md)）。
- **自主性有边界**：行动白名单 + 分级 + 打扰预算 + decision trace（[13](13-主动性架构.md)）。

## 5. 一天怎么跑

把散落的机制串起来，才是"整体"。

```text
07:50  早餐窗口 → 有理由（昨天说要记饮食）→ 开场「早餐吃了么？」
        你回「吃了」→ 写事实 → 今天不再问

09:30  QQ:「项目 X 什么情况？」
        → 画像=工作群（允许 task-progress）
        → 账本快照 3 小时前（过期）→ 派只读盘点任务给 X 的工作区
        → 90s 内回三行：进度/阻塞/下一步

11:00  午餐窗口 → 昨天说"可能不带饭" → 推荐三家（带理由）
        你回「今天带了」→ 记事实 → 建条件任务：明天 20:00 问想吃什么

14:00  自主循环发现：任务 X 落后 25%、1 小时无 harness 活动
        → L1 私聊：事实清单 + 「重排 / 现在做 30 分钟」
        → 你回了"马上做" → 冷却重置

16:30  仍无进展 → L2：三选一（改期 / 降范围 / 现在做），必须回
        你选改期 → 重排 → 契约更新 → 不再升级

20:40  明日窗口 → 冰箱清单 + 周三常加班 → 推荐两份 20 分钟能做的
        你选一份 → 采购清单 → 问要不要进待办

23:00  收工窗口 → 今日进展摘要 + 明天三件事（进摘要，不单独打扰）

03:00  夜间巩固 → 聚类/抽事实/分区 salience/剪枝
        报告：「记住 3 件重要的事，淡化 11 条闲聊」

某天   02:40 一个插件崩溃 → incident → 提案 → 你早上在手机上确认
        → 验证 → 换版 → 观察 10 分钟 → 写入 playbook
```

这一天的每个环节对应一个子系统；它们共享同一个记忆、同一个任务账本、同一套审计。

## 6. 数据流（一条消息的完整路径）

```text
入站 → 归一化(Block) → 画像(tags) → 策略求值(Envelope)
     → 记忆召回(audience 过滤) → 工具清单裁剪
     → 内嵌 DSH 生成 → 后置校验(禁词/长度/敏感)
     → 渠道发送 → 落库(message/turn) → 审计 → 异步抽取记忆
```

三个硬约束：**画像在模型之前生效**、**召回无副作用**、**不裁剪不下发**。

## 8. 路线图

从"能用"到"像贾维斯"，分七段。累计周数为单人全职。

| 阶段 | 累计 | 内容 | 交付感 |
| --- | --- | --- | --- |
| **P1 地基** | 6 周 | M0 内核 · M1 记忆基础 · M2 工具与日程 | 网页里能对话、能提醒、重启不丢 |
| **P2 手与口** | 10 周 | M3 QQ/飞书 · H harness 集成 | 在 QQ 里能用；能派任务给 DSH |
| **P3 贾维斯感** | 16 周 | A1 自主循环 · A2 排期白名单 · A3 项目审问 | 会主动找你、会汇报进度 |
| **P4 记忆复利** | 24 周 | N 神经元 · N+ 跨端 · G 群画像 | 记得住、多端不分裂、群里有分寸 |
| **P5 自我维持** | 30 周 | S1 自愈 · S2 playbook · R 周期复盘 | 坏了能修、每月自评 |
| **P6 督促** | 39 周 | W1–W5 合同/阶梯/摩擦/强制/休息 | 会催、会拦、也会让你歇 |
| **P7 完善** | 50 周 | A4–A8 开场 · M4 宿主 · M7 watch | 像管家而不是工具 |

**最短可用路径**：P1（6 周）就能日用；P2–P3（再 12 周）就有明显的"贾维斯感"。
其余是复利投资，按需启动，不必一次做完。

> **实现状态（2026-10-30）**：P1 中的 **M0 已落地**并通过验收（57 个测试 + 端到端冒烟全绿，
> 见 `../README-P1.md`）；M1（记忆）与 M2（工具与日程）尚未开始。

## 9. 成本与风险

| 项 | 判断 |
| --- | --- |
| 单人总工期 | 50 周（并行约 42）。建议按阶段验收，不要等全部完成 |
| 外部依赖 | Cordis 4 与 DSH 均为 rc/快速演进；锁版本 + 契约测试 |
| QQ 风控 | 非官方协议，存在封号风险；飞书/Web 优先 |
| 隐私 | 全本地；`secret` 不进云；出网需显式开启 |
| 记忆污染 | 召回只读、置信度只由外部证据提升、纠错最高优先 |
| 过度主动 | 预算 + 价值门槛 + 忽略学习 + 可一键关停 |
| 强制反噬 | 合同先行 + 逃生条款 + 失效安全 + 每日上限 |

## 10. 明确不做 / 推迟

- 多租户 SaaS（ADR-003）
- iOS 端强制措施（沙盒不允许）
- 跨设备统一锁屏（需厂商权限）
- 真正的 QQ 账号注销（不现实）
- 冰箱/饮食数据源、手环、常驻唤醒、本地大模型、智能家居 → 见 [16 Future](16-Future与硬件依赖.md)，每项带触发条件

## 11. 待拍板

**已定**：单用户多设备 · 移动端瘦客户端 · 标签固定+自定义（必须继承）· 未配置群回「权限未配置」·
每月周期复盘 · 范围先做工作侧 · 硬件相关全部进 future。

**待定（会影响实现）**：

1. **强制动作失败时默认放行还是坚持？** 我倾向放行 + 告警 + 第二次失败禁用该动作。
2. **C 类评估集由谁维护？** 每月人工抽检 50 条，还是做自动回归评分？
3. **是否公开发布？** 决定要不要做插件市场、文档站与 semver 承诺。
4. **首版是否内置本地模型？** 没有它，`secret` 数据完全不可用。
5. **人格语言**：中文单语，还是中英双语？
