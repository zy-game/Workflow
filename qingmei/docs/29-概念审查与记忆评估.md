# 概念审查与记忆评估

## 1. Web 记忆页

`apps/web/src/views/MemoriesView.vue`

两个视图：

```text
事实
概念提案
```

概念提案：

```text
评估 → 查看影响概念/事件/重叠/风险
应用 → 只允许 canApply 的 merge/split
回滚 → 单条或批量回滚已应用变更
```

split 需要至少两个 session 分组；应用时会创建新概念并保留快照。
批量回滚会按变更逐条恢复，失败时保留未恢复的变更。

接口：


## 2. 记忆质量评估

回归集：`scripts/fixtures/memory-eval.json`（**59 条中文查询 / 59 条事实**，含近义干扰项）。
评估脚本：`scripts/eval-memory.mjs`，在临时 SQLite 里灌事实后按顺序跑查询，统计 recall@1 / recall@3。

当前基线（2026-11-12，结果可复现，两次运行一致）：

```text
queries   59
recall@1  76.3%
recall@3  88.1%
阈值      recall@3 ≥ 80%（低于则 gate 失败）
```

已知漏召回（留给「是否上语义召回」那次决策做对照）：

| 查询 | 期望 | 现状 | 原因 |
| --- | --- | --- | --- |
| 我平时喝什么咖啡 | 手冲咖啡 | top3 全是别的咖啡事实 | 同一簇内「咖啡」权重相同，并列时按插入顺序 |
| 咖啡豆一般买哪里的 | 埃塞俄比亚 | 未进 top3 | 长对象里的「咖啡豆」被「咖啡」拆散 |
| 青梅监听哪个端口 | 7410 | 未进 top3 | 纯数字 token 激活弱 |
| 李四生日是几号 | 八月三号 | 未进 top3 | subject 里的「李四」被同人多条事实稀释 |
| 家里常备什么药 | 氯雷他定 | 未进 top3 | 查询词「药」只在 predicate，object 不含 |
| 我多久跑一次步 | 每周三次 | 第二名 | 与「每两周一次」共享数字 token |
| 我喜欢看什么电影 | 科幻电影 | 未进 top3 | 同上，单条事实被高频词淹没 |

注意：这是**词面回归集**，只说明当前神经元编码的能力边界，不代表真实用户分布；真实评估集仍未建立。
