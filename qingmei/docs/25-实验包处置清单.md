# 实验包处置清单

当前 `experimental/` 共 17 个包。这里不是“永久仓库”，每个包必须有处置结论。

建议分三档：

- **D：删除** — 已合并、已被替代、或没有继续维护价值
- **K：保留** — 有明确 owner 和重启条件
- **A：归档/合并** — 不单独保留，能力并入其它包或移出主仓库

## 建议立即删除（7 个）

| 包 | 原因 |
|---|---|
| `provider-approval-sqlite` | 已并入 `qm-approval` |
| `provider-audit-sqlite` | 已并入 `qm-audit` |
| `qm-reminder` | 已并入 `provider-schedule-sqlite` |
| `qm-thread` | 已并入 `qm-history` |
| `qm-consolidate` | 新记忆没有 consolidate 概念 |
| `qm-memory-extract` | 已决定不做每轮 LLM 抽取 |
| `qm-memory-hotspot` | 依赖旧记忆命中/评分模型，已不兼容 |

这 7 个是“已确认的重复/死能力”，删除不会损失当前主链路。

## 建议合并或归档（6 个）

| 包 | 建议 |
|---|---|
| `qm-autonomy` | 保留为自治入口 |
| `qm-incident` | 并入自治/运维闭环，或保留但明确 owner |
| `qm-nudge` | 并入自治（督促是自治动作） |
| `qm-opener` | 并入自治（主动开场） |
| `qm-rest` | 并入自治或日程（休息提醒） |
| `qm-conversation-profile` | 如果只做个人 Jarvis，删除；如果保留群聊，明确 owner |

## 可选基础设施（2 个）

| 包 | 建议 |
|---|---|
| `provider-llm-openai` | 只有确定要做“显式模型池/降级”才保留，否则删除 |
| `provider-embedding-openai` | 只有确定做向量记忆才保留，否则删除 |

## 非主链路，建议归档或删除（2 个）

| 包 | 建议 |
|---|---|
| `qm-content` | 内容运营不属于个人助手核心 |
| `qm-review` | 月度复盘有价值，但应作为可选报表，不默认保留 |

## 处置原则

```text
删除 > 归档 > 留在 experimental
```

`experimental/` 里的包如果没有：

```text
owner
重启条件
复审日期
```

就不应该继续存在。

## 建议执行顺序

```text
第一批：7 个已确认重复/死能力
第二批：autonomy / incident / nudge / opener / rest 合并成一个自治包
第三批：content / review / conversation-profile 按产品方向决定
第四批：OpenAI provider 按模型池/向量方案决定
```

第一批可以先做，风险最低。
