`qm-autonomy` 已从 experimental 提升为默认装配。

由 `qm-autonomy` 统一持有；通过：

```yaml
- name: '@qingmei/qm-autonomy'
  config:
    modules: true
```

启用整组自治能力。默认 `modules` 关闭，避免实验模块互相耦合。
