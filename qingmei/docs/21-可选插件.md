# 可选/已下线插件

主装配 `qingmei.yml` 只保留个人助手核心链路。以下能力代码仍保留在仓库，但默认不加载：

| 插件 | 状态 | 原因 |
|---|---|---|
| `@qingmei/qm-content` | 默认下线 | 内容发布/账号运营，不是个人助手主链路 |
| `@qingmei/qm-review` | 默认下线 | 月度复盘直接读取 task/message/incident collection，先不进入主装配 |
| `@qingmei/qm-memory-hotspot` | 默认下线 | 直接调整 memory collection；先收敛为记忆服务能力 |
| `@qingmei/qm-opener` | 默认下线 | 主动开场实验模块，先不进入主装配 |
| `@qingmei/qm-nudge` | 默认下线 | 任务督促实验模块，先不进入主装配 |
| `@qingmei/qm-rest` | 默认下线 | 休息提醒实验模块，先不进入主装配 |

重新启用时，把它加回 `qingmei.yml`，并确保它只通过 owner 服务读取数据，而不是直接 `store.collection()`。
